Comment jouer
  • ●Tape le pad quand la note arrive sur lui.
  • »Flèche : glisse le doigt dans son sens.
  • ∿Trait violet : tape la 1re note, garde le doigt et glisse vers les suivantes.
  • ┃Note tenue : garde le doigt posé jusqu'au bout du trait.
  • ━Barre dorée : tape n'importe où.
  • ★Réussis les notes étoilées, puis tape la barre cyan : le Mode Drop double tes points.
  • ✕Une note ratée étouffe le son jusqu'à ta prochaine note réussie.
Au clavier : D F J K pour les pads, ← → pour les flèches, Espace pour le Mode Drop.
Un nouveau titre se débloque chaque vendredi jusqu’à la sortie de l’album.
